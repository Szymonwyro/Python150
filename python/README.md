# LeetCode150

One folder per DS&A topic (matching the taxonomy in `../progress.md`), each
with a README stub. Drop solutions in as you (re-)solve problems, and log
them in `../progress.md`'s Problem Log under the DS&A / LeetCode domain.

This is a fresh structure, not a migration of anything — organize it however
actually works for you; the topic folders are just a reasonable starting
point matching what the dashboard tracks.

Five topics (`arrays-strings`, `two-pointers`, `sliding-window`, `hashing`,
`binary-search`) are seeded with 2 practice files each — a numbered `.py`
file with the problem statement in a docstring, a stub function with
`# TODO`, and a `__main__` block of asserts so you get an immediate
pass/fail when you run it (`python3 01_two_sum.py`). Fill in the function
body; leave everything else alone so the self-check still works. Once you
solve one, log it in `../progress.md`'s Problem Log — or just tell Claude
what you solved and it'll log it for you. The other 14 topic folders are
still empty stubs — same pattern, just ask if you want more seeded.
